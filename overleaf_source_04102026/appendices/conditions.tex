\section{Additional Conditions}
\label{appendix:conditions}

This section supports the last paragraph of~\autoref{subsec:overall_performance}: four conditions,
each run after the main analysis on the originals of the 450-instance subset (three instances per
template), each changing one thing while keeping the main run's prompt, output ceiling, and scoring,
and each labeled exploratory (\autoref{appendix:protocol}).
A condition is compared with its base run paired by instance: the mean change, a template bootstrap
interval, a sign-flip test over templates with Holm correction across the models in the condition,
the smallest paired change the condition detects at 80\% power, and the 90\% interval against the
$\pm 0.05$ margin.
The main run's scores remain the headline; a condition says what one change costs or buys.

\paragraph{Reasoning Effort.}
The two closed models that return no reasoning tokens at their providers' defaults,
\texttt{GPT-5.4 mini} and \texttt{Gemini 3.1 Flash-Lite}, answer the subset again with the
provider's reasoning-effort parameter set to medium.

\paragraph{Flagship Anchors.}
Two flagships that pass the selection rule, \texttt{GPT-5.4} and \texttt{DeepSeek V4 Pro}, answer
the subset at their providers' defaults, and \texttt{GPT-5.4}, whose default returns no reasoning
tokens, also with reasoning at medium effort.
An anchor is a reference point outside the pairwise family: no test is run against it,
and~\autoref{tab:anchors} places the anchors beside the eleven evaluated models' main-run responses
on the same instances.

\paragraph{Governing Equations.}
For the 135 templates whose code states their governing equations in symbols, we append to the
question a block headed as reference equations from an engineering handbook, one equation per line,
taken from the template's own statement of its equations; the 15 templates without such a statement
are left out, so the condition holds 405 instances.
The condition supplies no data tables or constants beyond what the equation lines carry, so a
template whose difficulty lies in a property lookup is not helped by it.
One model from each tier answers: \texttt{Claude Sonnet 5}, \texttt{GPT-5.4 mini}, and
\texttt{gpt-oss-20b}.

\paragraph{Code Tool.}
With the prompt unchanged, the request offers one function tool, a Python interpreter for arithmetic
and numerical computation with the standard library, NumPy, SciPy, and SymPy, which the model may
call or not.
A called script runs in a fresh isolated interpreter in a scratch directory, with no credentials in
its environment, a 20 s limit, and its output truncated at 4,000 characters; a static filter refuses
scripts that reach for the file system, the network, processes, or introspection, and the model sees
the refusal as the tool's output.
A response may make up to 8 calls, after which one more turn without the tool ends it in an answer;
the transcript, with each script and its output, is what the evaluator scores.
\texttt{Claude Sonnet 5} and \texttt{GPT-5.4 mini} answer under this condition; the endpoints that
our provider rule admits dropped \texttt{gpt-oss-20b}'s tool calls or rate-limited the requests, so
the open-weights tier is absent from this condition.

\paragraph{Results.}
\autoref{tab:conditions} gives every condition against its base run, and~\autoref{tab:anchors}
places the anchors beside the evaluated
models.
Reasoning at medium effort moves \texttt{GPT-5.4 mini} by 0.093 (95\% CI 0.056 to 0.133) and
\texttt{Gemini 3.1 Flash-Lite} by less than the condition detects.
Neither flagship exceeds the top tier: the top five on the same instances score 0.964 to 0.976, with
intervals that contain both reasoning anchors, and on Advanced templates 0.92 to 0.95 against the
anchors' 0.87 to 0.95.
The governing equations lift \texttt{gpt-oss-20b} by 0.064 (95\% CI 0.027 to 0.104), partly because
fewer responses run out of room (0.043 on the instances answered in both runs), and leave the two
closed models within the margin, while MC rises by 0.03 to 0.06 for all three because the supplied
equations prompt the responses to state the intermediates.
The tool changes neither closed model beyond the margin, and \texttt{GPT-5.4 mini}'s arithmetic
flags on correct answers fall from 0.127 to 0.093.
No condition says where the remaining errors lie; that is the question the expert reading
of~\autoref{subsec:error_analysis} answers.
