\subsection{Decoding and Token Use}
\label{appendix:decoding}

We query every model through OpenRouter with the prompt (\autoref{appendix:prompt}) and the output
ceiling, and set no temperature, top-p, or reasoning setting, so each model decodes at its
provider's defaults.
The ceiling is 32,768 tokens, except 16,384 for \texttt{Muse Glimmer 30B}, whose single eligible
provider caps its output there.
Providers serve every open-weights model at 8-bit floating-point precision or higher, and the
responses of one model can come from several providers.
A request that fails at the provider is sent again, and every model returns one response, possibly
empty, for each of the 2,250 instances.
\texttt{Qwen3-235B-2507} has no thinking mode, and \texttt{Gemma 4 26B},
\texttt{Gemini 3.1 Flash-Lite}, and \texttt{GPT-5.4 mini} return no reasoning tokens at their
providers' defaults; the other seven models return them on nearly every response.

\subsection{Inference Prompt and Output Processing}
\label{appendix:prompt}

To ensure consistent and parsable outputs across all models, we use a standardized zero-shot prompt,
sent as a single user message with the instance's question in place of \texttt{\{question\}}.
This prompt explicitly instructs the model to structure its response with specific headings and to
format the final result for automated extraction.

\begin{quote}
\small
\begin{verbatim}
You are an expert engineer. Solve the following
problem by providing a detailed, structured
solution. Use the exact headings and
formatting provided below.

## Given
List all known variables and their
values with units.

## Find
State the variable(s) to be calculated.

## Formulae
Write down all necessary governing equations
before substituting any values.

## Solution
Provide a step-by-step calculation. Each step
must start on a new line and be formatted exactly
as '**Step X:**', where X is the step number.
Show the substitution of values into
the formulae clearly.

## Final Answer
State the final numerical result with its units
in the format: **Answer:** [value] [units]

Problem:
{question}
\end{verbatim}
\end{quote}

Each check reads the response as~\autoref{appendix:scoring} describes:
\begin{itemize}
    \item \textbf{Final answer}: the check reads the answer after the last final-answer heading or
    the \texttt{**Answer:**} marker, and still reads a response that has neither.
    \item \textbf{Milestones and arithmetic}: milestone matching searches the whole response, in any
    order, and the arithmetic check reads every calculation the response displays.
    \item \textbf{Judged steps}: the judged step check splits the response into steps the same way
    as in the expert study.
\end{itemize}

\subsection{Statistical Protocol}
\label{appendix:protocol}

The template is the unit of analysis (\autoref{subsec:setup}): every template has 15 instances, so
Final Answer Accuracy over the 2,250 instances equals the mean of the 150 template means.
On this unit, we estimate and test each quantity as follows:
\begin{itemize}
    \item \textbf{Intervals}: every 95\% interval is a percentile bootstrap that resamples templates
    10,000 times, and a bounded change also carries its 90\% interval.
    \item \textbf{Two models}: we compare them on the per-template differences of their scores, with
    a paired bootstrap interval and a sign-flip permutation test with 100,000 sign flips.
    Strict accuracy, which scores a partial answer 0, and McNemar's exact test on the paired
    verdicts check the comparisons of Final Answer Accuracy; a Wilcoxon signed-rank test checks
    those of Milestone Coverage, which use the 147 templates with milestones.
    \item \textbf{Level gaps}: a model's level gap is its mean on the 58 Easy templates minus its
    mean on the 34 Advanced ones; we test it with Welch's $t$-test on the template
    means~\citep{welch1947generalization}, because scores vary more across Advanced templates, and
    its interval resamples templates within each level.
    \item \textbf{Orderings}: we compare two orderings of the models with Kendall's $\tau$ and a
    bootstrap interval.
    \item \textbf{Multiple tests}: Holm's correction~\citep{holm1979simple} applies within each
    family of tests, such as the 55 pairs of models for each measure or the eleven level gaps.
    \item \textbf{Detectable differences}: at 80\% power and a two-sided level of 0.05, a paired
    comparison detects $2.80\,s/\sqrt{n}$, with $s$ the standard deviation of the $n$ per-template
    differences, and a level gap $2.80\,\sigma\sqrt{1/58 + 1/34}$, with $\sigma$ the pooled
    standard deviation of the template means within a level.
    \item \textbf{Bounded changes}: a change counts as bounded when its 90\% interval lies within
    $\pm 0.05$, which is two one-sided tests at 5\%.
\end{itemize}
