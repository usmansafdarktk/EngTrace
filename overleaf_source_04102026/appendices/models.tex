\subsection{Decoding and Token Use}
\label{appendix:decoding}

We query every model through OpenRouter, and each request carries the prompt
(\autoref{appendix:prompt}), the output ceiling, and routing preferences only,
with no temperature, top-p, or reasoning setting, so each model decodes at its provider's defaults.
OpenRouter sends each open-weights model to the cheapest provider that serves it at 8-bit
floating-point precision or higher, and to the next one when a request fails, so the responses of
one model can come from several providers.
A request that fails at the provider is sent again, and every model returns a response, possibly
empty, for all 2,250 instances.
\texttt{Muse Glimmer 30B} has a single eligible provider, which caps its output at 16,384 tokens.
Four models return no reasoning tokens: \texttt{Qwen3-235B-2507} has no thinking mode, and
\texttt{Gemma 4 26B}, \texttt{Gemini 3.1 Flash-Lite}, and \texttt{GPT-5.4 mini} return none at
their providers' defaults.
\autoref{tab:decoding} gives each model's ceiling, providers, token use, responses without a
readable final answer, and cost; the 24,750 responses cost US\$247.92 in all.

\subsection{Inference Prompt and Output Processing}
\label{appendix:prompt}

To ensure consistent and parsable outputs across all models, we use a standardized zero-shot prompt,
sent as a single user message with the instance's question in place of \texttt{\{question\}}.
This prompt explicitly instructs the model to structure its response with specific headings and to
format the final result for automated extraction.
Every response records the SHA-256 hash of the prompt template, and all 24,750 carry the same one.

\begin{quote}
\small
\begin{verbatim}
You are an expert engineer. Solve the following
problem by providing a detailed, structured
solution. Use the exact headings and
formatting provided below.

## Given
List all known variables and their
values with units.

## Find
State the variable(s) to be calculated.

## Formulae
Write down all necessary governing equations
before substituting any values.

## Solution
Provide a step-by-step calculation. Each step
must start on a new line and be formatted exactly
as '**Step X:**', where X is the step number.
Show the substitution of values into
the formulae clearly.

## Final Answer
State the final numerical result with its units
in the format: **Answer:** [value] [units]

Problem:
{question}
\end{verbatim}
\end{quote}

The final-answer check does not require the prompt's format: it reads the answer after the last
final-answer heading or the \texttt{**Answer:**} marker, and still reads a response that has
neither, while milestone matching and the arithmetic check read the whole response
(\autoref{appendix:scoring}).


\subsection{Statistical Protocol}
\label{appendix:protocol}

\paragraph{Unit and Intervals.} The template is the unit of analysis (\autoref{subsec:setup}).
Every template has 15 instances, so Final Answer Accuracy over the 2,250 instances equals the mean
of the 150 template means, and comparisons of Milestone Coverage use the 147 templates with
milestones.
Every 95\% interval is a percentile bootstrap that resamples templates 10,000 times, and where we
bound a change, we also give its 90\% interval.

\paragraph{Tests.} We compare two models on the per-template differences of their scores, with a
paired bootstrap interval and a sign-flip permutation test with 100,000 sign flips.
For Final Answer Accuracy, the same test on strict accuracy, which scores a partial answer 0, and
McNemar's exact test on the paired verdicts serve as checks; for Milestone Coverage, a Wilcoxon
signed-rank test does.
A model's level gap is its mean on the 58 Easy templates minus its mean on the 34 Advanced ones;
its interval resamples templates within each level, and Welch's $t$-test on the template
means~\citep{welch1947generalization} tests it, because scores vary more across Advanced templates.
We compare two orderings of the models with Kendall's $\tau$ and a bootstrap interval.

\paragraph{Corrections and Power.} Holm's correction~\citep{holm1979simple} applies within each
family of tests, such as the 55 pairs of models for each measure or the eleven level gaps.
The smallest difference that a paired comparison detects at 80\% power and a two-sided level of
0.05 is $2.80\,s/\sqrt{n}$, with $s$ the standard deviation of the $n$ per-template differences;
for a level gap it is $2.80\,\sigma\sqrt{1/58 + 1/34}$, with $\sigma$ the pooled standard
deviation of the template means within a level.
A change counts as bounded when its 90\% interval lies within $\pm 0.05$, which is two one-sided
tests at 5\%; we fixed this margin after the point estimates of the rewording test were known.

\paragraph{Planned and Exploratory Analyses.} We fixed the questions, the unit, the scoring rules,
and the tests before running any model: Final Answer Accuracy per model and the 55 comparisons
between models, the level gap per model, Milestone Coverage on wrong answers and the two
diagnostics on correct answers as descriptions with intervals, consistency within templates, and
the rewording test.
One planned test is replaced: the level gap uses Welch's $t$-test instead of a permutation of the
level labels, which is liberal when the level with fewer templates varies more.
The analyses we added afterwards are labelled exploratory where they appear: Milestone Coverage
over all responses and its comparisons between models, the branch and level means with intervals,
the sensitivity analyses added after the first results, and the four conditions on the
450-instance subset.
