Metrics key
  % Agree   : Raw pairwise percent agreement
  Cohen's κ : Chance-corrected agreement (sensitive to prevalence imbalance)
  PABAK     : Prevalence-Adjusted Bias-Adjusted Kappa = 2·p₀ − 1

  Fleiss' κ : Multi-rater chance-corrected agreement (all 3 annotators)
  Kripp. α  : Krippendorff's α, nominal scale (all 3 annotators)
  NOTE: Fleiss' κ = Krippendorff's α is mathematically expected for 3
        raters with complete nominal data — not a computational error.
